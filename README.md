# ai-animtions

This project uses an AI model that runs locally to generate characters. The end goal is to turn those characters into animations.

## Goals

1. **Character creation:** Generate characters with a local AI model. No cloud APIs needed.
2. **Animation:** Use the generated characters to create animations.

## Setup

Requires Python 3.11+ and [uv](https://docs.astral.sh/uv/).

```
uv sync
uv run ai-animtions
```
